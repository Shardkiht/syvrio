# Syvrio Evo 产品需求文档

- 适用分支：`feature-memory-evolution`
- 文档状态：现行产品基准
- 更新日期：2026-11-15

## 产品定位

Syvrio 是面向个人的本地优先记忆助手。用户能保存、查找和修订跨会话事实，并随时查看来源。Evo 在稳定记忆流程之上验证时间演化、推断审查、反思和画像。长期事实由用户控制，衍生视图根据有效证据更新。

## 用户与场景

| 场景 | 用户需要 | 验收示例 |
| --- | --- | --- |
| 跨会话协作 | 新会话能查到此前确认的偏好、约束和计划 | 在独立会话中提问，回答引用有效事实并能追溯 Vault 记录 |
| 变更与更正 | 区分过去真实发生的状态与原有记录错误 | 状态变化保留历史，当前与指定日期的查询给出对应事实 |
| 待确认与推断 | 在确认前能检查候选原文、来源及冲突 | 确认、拒绝和更正后的列表、召回和审计一致 |
| 持续阅读 | 手机切后台或临时断网后能回到同一轮回复 | 断开流后回复继续，回到会话读取同一条完整结果；「停止」取消当前轮 |
| 跨客户端访问 | 浏览器、命令行和 MCP 能使用同一个 Vault | 在受支持入口写入一条事实，在另一入口能召回同一 ID |

## Foundation 与 Evo

| 能力 | Foundation | Evo |
| --- | --- | --- |
| 基础对话、Vault V2、UTC、CLI、Web、TUI 与 MCP | 稳定维护范围 | 共用契约，继续同步通用修复 |
| 记忆写入、检索、待确认与修订 | 保留稳定行为与审计 | 增强短字段召回、结构化上下文和时间视图 |
| 推断审查、原事实状态演化、反思与画像 | 独立于稳定主链路 | 实验性能力，按证据和回归结果逐步完善 |
| 安装和升级 | 稳定发布频道 | PyPI 预发布及 Evo 更新频道 |

## 功能需求与验收

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| FR-01 | 支持会话创建、切换、查看历史、取消、撤销及上下文压缩 | 待沉淀会话在后台补记；失败或取消时游标可恢复，快照失效时保留待处理消息 |
| FR-02 | 区分明确记忆、抽取候选、冲突和敏感输入 | 已识别凭据被阻断；低置信或冲突条目进入待确认；更正与删除有审计 |
| FR-03 | 召回支持关键词、向量和混合模式，以及上下文约束 | 短字段的精确证据有优先级；向量不可用仍返回关键词结果；合成基准覆盖不同问题类型 |
| FR-04 | 区分事实变化与事实纠错 | `evolve` 按生效日期形成历史序列；`correct` 修正错误；纯日期精度保留 |
| FR-05 | 独立存储推断和用户审查结果 | 每个推断可查到来源 ID；拒绝、修订或证据失效后，活动视图及时更新 |
| FR-06 | 允许显式回顾和查看画像 | 画像可追溯且能标明过期；选择性运行遵守请求预算；取消保留已完成进度 |
| FR-07 | 管理模型、供应商和搜抓取选项 | 列表来自 API；按凭据区分缓存；切换显式进行；当前模型失败时保留错误与重试语义 |
| FR-08 | 提供 Web 和非交互 CLI，维护 TUI 和 MCP | Web 流式跟随尊重手动上滑；受限工具入口保持能力边界；本地包带完整 Web 静态资源 |
| FR-09 | 稳定升级与数据恢复 | 合成历史 Vault 完成备份、只读预览、迁移、读取验证和恢复演练；更新器按频道选包并执行健康检查 |

## 质量与交付

- 真实记忆、凭据和推理附件留在其约定的数据边界。联网检索结果按外部资料处理。诊断和评测用合成数据或汇总指标。
- Web 默认本机监听。没有内置登录的部署仅置于受信网络。
- 在 Debian 13 验证 Python、Web 前端、CLI、打包和迁移。供应商特有行为、真实手机和终端分别记录验证范围。
- 新的高级记忆行为先进入 Evo。稳定线提取已通过回归、隐私与升级验证的独立改动。发版、生产部署与真实 Vault 迁移各自确认。
